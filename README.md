# Digital Thermometer using STM32

## Overview
A digital thermometer PCB designed using KiCad and based on the STM32 microcontroller. The system measures temperature using an LM35 sensor and can be integrated with a display for real-time temperature monitoring.

## Features
- STM32 Microcontroller
- LM35 Temperature Sensor
- KiCad PCB Design
- 2-Layer PCB
- Embedded C Firmware

## Software Used
- KiCad
- STM32CubeIDE
- Embedded C

## Hardware
- STM32 Microcontroller
- LM35 Temperature sensor
- 16*2 LCD
- Resistors
- Capacitors
- Crystal Oscillator

- Schematic (.kicad_sch)
- PCB Layout (.kicad_pcb)
- KiCad Project (.kicad_pro)
